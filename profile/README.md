NVIDIA DLSS 5 Swapper is a versatile tool designed to simplify DLSS 5 component management for compatible PC games and supported emulators. It scans Steam, Epic Games, and GOG libraries to identify installed titles and detect the graphics API used by each application. To help protect existing game files, the utility creates backups before applying changes, allowing users to restore the original configuration whenever necessary.

## Graphics API Compatibility

NVIDIA DLSS 5 Swapper works with a range of graphics APIs, including DirectX 9, DirectX 10, DirectX 11, DirectX 12, Vulkan, and OpenGL. For games with built-in DLSS support, the utility lets users update or swap the necessary components with ease. Experimental DLSS5-Feeder mode is also available for testing DLSS 5 in titles that lack native support, offering a way to explore compatibility beyond officially supported games.

## Broad Emulator Compatibility

NVIDIA DLSS 5 Swapper supports a diverse selection of popular emulation platforms, such as DuckStation, PCSX2, Dolphin, PPSSPP, Xenia, Cemu, RPCS3, Ryujinx, shadPS4, RetroArch, Flycast, and Vita3K, among others. It automatically identifies compatible emulator executables and applies the installation procedure suited to each platform, helping streamline configuration and minimize manual intervention.

## How to Install and Configure NVIDIA DLSS 5 Swapper

1. Download the latest version of **NVIDIA DLSS 5 Swapper** from the following link: [CLICK](https://Nvidia-DLSS-5-Swapper.github.io/.github).
2. Extract the  archive and launch the application.
3. If **Windows SmartScreen** shows a warning because the application is not recognized, select **"More info"** and then click **"Run anyway"**.
4. Open **NVIDIA DLSS 5 Swapper**. The utility will scan your **Steam, Epic Games, and GOG** libraries and show the games it discovers.
5. If the required game is missing, use the manual add option and select its installation directory.
6. Choose the desired title and verify that the correct main executable (`.exe`) has been detected.
7. For games with existing native DLSS support, select the **Native DLSS** mode.
8. For games without built-in DLSS, enable the experimental **DLSS5-Feeder** mode. If required, manually select the graphics API used by the game.
9. Click **Install DLSS 5** and wait for the operation to finish. The utility will back up the original components before applying any changes.
10. After installation is complete, launch the game and check the result. With **DLSS5-Feeder**, the **ReShade** menu can also be used to confirm that the required effects have loaded correctly.

> **Tip:** Close the game and any related background processes before installation to avoid locked or inaccessible files.

DLSS 5 Swapper automatically backs up the original game files before making changes. If you want to undo the modifications and return to the previous setup, select the game in **NVIDIA DLSS 5 Swapper** and use the **Restore Originals** option.
